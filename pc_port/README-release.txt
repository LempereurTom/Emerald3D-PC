Emerald PC
==========

An unofficial PC port of Emerald 3DS by Zallax and contributors
(https://github.com/ZallaxDev/emerald-3ds), itself a native port of
Pokémon Emerald. Modified for the PC: windowed and fullscreen display, the
FUSION single-screen layout, keyboard and gamepad controls, volumes, ambient
particles and weather. No emulator.

This download does NOT contain the game. You need your own dump of your own
cartridge, in this release's language (see the file name: -fr is
Pokémon Version Émeraude, France). On its first run the game asks for that
ROM and makes its data from it, on this computer, once (a few minutes). The
ROM is only read: it is not uploaded, copied or modified. An Internet
connection is only used to download the optional follower sprites.

Running
-------
- Windows: emerald-pc.exe.
- Keep the folder as it is: engine/, payload/ and the builder must stay next
  to the executable.
- Saves, settings and the game data go to %APPDATA%\EmeraldPC (Windows) or
  ~/.local/share/emerald-pc (Linux). Saves are those of Emerald 3DS: the same
  emerald3ds.sav works on both.
- To make the data again (another ROM, a damaged install): delete the
  devdata folder there; the game asks for the ROM on its next start.

Keys (OPTIONS > CONTROLS to change them): arrows, X (A), Z (B), S (X),
A (Y), Q (L), W (R), Enter (START), Backspace (SELECT). F9 changes the
screen layout, F11 fullscreen. In FUSION: P party, I bag, F5 save,
O options, Shift run, M map.
